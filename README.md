# 🎓 Academic Landing Page

A modern and responsive academic landing page designed to present educational content in a clean and engaging way.

🔗 Live Demo: https://mohamedzarea2002.github.io/academic/

---

## 🚀 Overview

This project is a simple academic landing page that focuses on delivering a clear message and structured content for educational purposes.  
It highlights modern UI design, smooth layout, and user-friendly experience.

---

## ✨ Features

- Clean and modern UI design
- Fully responsive across all devices
- Well-structured sections (Hero, About, Services, Contact)
- Smooth and simple user experience
- Lightweight and fast performance

---

## 🧰 Tech Stack

- HTML5
- CSS3
- JavaScript

---

## 📂 Project Purpose

This project was built as a practice to improve frontend development skills, focusing on:

- Building landing pages
- Improving UI/UX design skills
- Creating responsive layouts
